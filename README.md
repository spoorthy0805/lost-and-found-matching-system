# Lost & Found Matching System

A web-based application that allows users to report lost and found items and receive possible matching suggestions based on item details.

## Team

Member 1: Shristi Shukla

Member 2: Spoorthy M

## Main Features

* User registration and login
* Lost item reporting
* Found item reporting
* Search and filtering
* Smart matching
* Claim submission
* Admin verification

## Planned Technology Stack

* Frontend: Next.js
* Backend: Next.js API Routes / Route Handlers
* Database: PostgreSQL
* Vector Search: pgvector
* Version Control: GitHub
